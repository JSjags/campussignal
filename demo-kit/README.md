# CampusSignal demo kit

These materials support the shared learner demonstration described in the [project README](../README.md). They contain demonstration learning content; the app does not execute or academically verify the code described in submissions.

| File                                                              | Use                                                                                                                                                             |
| ----------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [Module outline PDF](CSC204-REST-Auth-Testing-module-outline.pdf) | Import from Add a module to demonstrate browser-side PDF text extraction. Review the extracted text and confirm outcomes before task creation.                  |
| [Printable demo sheet](CampusSignal-demo-copy-paste-sheet.pdf)    | Reference while presenting the module/restart and Phone a Friend journeys.                                                                                      |
| [Copy-and-paste text](CampusSignal-demo-copy-paste.txt)           | Request topic, explanation of the 401 error, Tunde’s response, Amaka’s reply, module title and restart evidence. Paste only the relevant block into each field. |

For the shortest walkthrough, sign in as Amaka, send “stuck” to Coach, and request Tunde through Phone a Friend. Switch persona to Tunde, accept, chat and complete; switch back to Amaka and complete. Both receive UNSTUCK only after both finish. Separate browser profiles can show both learners at once; normal tabs share the same identity.

For the alternate restart journey, use Amaka’s seeded task or import the outline PDF, confirm an action-oriented outcome, read the rubric and submit the supplied written evidence. The optional timer does not gate submission.

Shared demo actions persist. Run `npm run seed` only against a disposable store to restore the original scenario. Never enter private learner information into shared personas.
